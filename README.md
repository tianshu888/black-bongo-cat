# 小黑猫 3D 桌宠 (Black Bongo Cat 3D Desktop Pet)

基于 Electron + Three.js + uiohook-napi 打造的 3D 卡通渲染桌面宠物，支持透明无边框置顶、全局键鼠动作同步、舒适左键撸猫、以及系统托盘独立自定义设置面板。

## 核心特性

- **13 种真实全身猫咪预设动作**：
  - 支持 **趴睡打盹、双手捧吃猫条、瑜伽伸懒腰、俯身干饭、圆润面包揣手、伏地摇屁股抓飞虫、空中 360° 翻跟斗、深夜跑酷、洗脸、舔爪/追尾、钻纸箱**，通过脊柱髋部关节与手臂 IK 联动告别“全程端坐”，可在设置「动作演示」或托盘右键随时触发欣赏。
- **3D Toon + 菲涅耳轮廓渲染**：
  - 使用定制 GLSL 着色器（`bodyFurMat` / `armFurMat` / `limbFurMat`），呈现哑光黑猫绒毛质感，同时在弯曲短手、肉垫与小脚上勾勒纤细银灰边缘高光。
  - 平贴脸廓的 3D 杏仁猫眼、大范围扫视瞳孔（支持全局视线跟随与扫键追视）、以及可闭合成温柔眼缝的 3D 上下眼睑。
- **爆发式打字打击感**：
  - 按下左/右区按键时分别伸出对应短臂（空格左右交替），第 0 帧瞬间抬爪蓄力、第 2 帧狠狠砸下，伴随肉垫挤压形变、整把机械键盘机械下沉倾斜回弹、荧光绿星芒扩散环与轻盈上浮淡出的立体字母键帽。
  - 键帽表面自带清晰小字标识（`ESC`、`Q W E R`、`A S D F`、`Caps`、`FN` 等）。
- **自然伸手握鼠与前侧高亮**：
  - 右臂沿外肩轮廓斜向握住鹅卵石鼠标上方，前侧露出白色鼠标弧面与滚轮，左右键点击时精准亮起前方对应的半区，不被猫爪遮挡。
- **零打扰交互与舒服撸猫**：
  - 鼠标普通经过/悬停不触发拖动或眯眼，空白与道具区默认点击穿透。
  - **按住鼠标左键拖动小猫**：进入惬意撸猫状态，微抬头迎合、眯成开心眼缝、脸颊浮现淡淡暖粉色腮红、轻摇尾巴并伴随呼噜/喵叫音效（不剧烈拽头摇晃），同时增加心情与亲密度，累趴时还可加速回体。
  - **按住鼠标右键小猫**：在小猫旁侧浮现轻量状态栏（显示钱包余额、经验值比例、开心/饱食/体力），**松开右键立即消失**。
  - **按住 `Alt + 鼠标左键` 拖动小猫**：自由调整桌宠在桌面上的位置。
  - **按住 `Alt + 鼠标左键双击小猫`**：打开完整的「档案与商店 / 外观设置」弹窗。
  - **不抢焦点无顶栏框**：主窗口采用纯 `WS_POPUP` + `WS_EX_NOACTIVATE`（`focusable: false`、`showInactive()`），避免 Windows 非客户区渐变标题栏条带与键盘焦点抢占。
- **首次启动入职申请表与电子工牌**：
  - 新电脑首次双击打开会自动弹出「左填表 + 右实时工牌」申请表，填写主人名字/猫咪称呼、猫咪花名、纯趣味真猫技能与爱好（会翻跟斗/会抓虫子/会开门等），支持**现场 3D 猫拍照直出工牌照**或上传真猫照片；工牌随 `Lv.1~Lv.10` 升职不断进阶。
- **打工喵职业养成与体力系统**：
  - 短视频电商公司 **10 阶每级必涨底薪晋升**（`Lv.1 实习打杂喵 1 币 → Lv.2 剪辑喵 2 币 → ... → Lv.10 MCN 喵老板 16 币/次`），商店物价与升职红包随获取难度与功能价值平衡匹配；干活消耗体力与饱食度，体力归 `0` 累趴慢慢回体，喂食猫粮/猫条/罐头急速回体秒醒。
- **系统托盘自定义设置面板**：
  - 单击系统托盘小黑猫图标打开独立设置窗口（支持 **50% ~ 180%** 无级缩放、**樱花粉白 / 草莓甜粉 / 薄荷奶油 / 香芋浅紫 / 极客酷黑 / 经典白橙** 6 套键盘主题、4 种鼠标配色、4 种猫咪毛色、5 种瞳色及特效/置顶/锁位开关，自动保存到 `AppData\Roaming\BlackBongoCatPet\bongo-settings.json`）。

## 目录结构

- `electron/main.js`：无边框非激活桌宠窗口、系统托盘菜单、全局键鼠钩子（`uiohook-napi`）、设置/养成数据持久化
- `electron/preload.js`：安全的 `contextBridge` 渲染进程通信接口
- `src/catRig.js`：Three.js 3D 猫身骨骼、定制 GLSL 着色器、3D 小舌头、腮红、瞳孔缩放与解锁饰品
- `src/props.js`：3D 键盘/鼠标与按需短暂生成的猫粮碗/猫条/罐头/逗猫棒/毛线球/飞虫/纸箱特效
- `src/behaviors.js`：打工经济/体力累趴与 12 种自主行为（洗脸/伸懒腰/揣手/打盹/追尾/跑酷/抓虫）状态机
- `src/careers.js`：短视频电商公司 10 阶职业晋升表（含网感签名、升职红包与工作经验成长计算）
- `src/app.js`：主场景组装、点击穿透、左键舒服撸猫与动画主循环
- `src/settings.html` / `src/settings.js`：双页签独立窗口（`🐾 档案与商店` 含随职级进阶电子工牌 + `⚙ 外观设置`）
- `src/onboarding.html` / `src/onboarding.js`：首次启动自动弹出的新员工入职申请表与 3D 工牌拍照工作室
- `src/sound.js`：Web Audio API 合成打字、呼噜、喵叫、咔嚓吃粮、舔猫条、铃铛等全套音效
- `assets/icon.png`：256×256 应用图标
- `启动小黑猫.bat`：开发态一键启动脚本（清理冲突的 `ELECTRON*` 环境变量）

## 开发与打包

```bash
# 安装依赖
npm install

# 本地开发启动（若系统存在冲突 ELECTRON* 环境变量，建议运行 启动小黑猫.bat）
npm start

# 打包为单文件便携版 Windows exe (输出至 dist/小黑猫桌宠.exe)
npm run build
```
